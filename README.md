* 3.

ID: Garante que os passageiros sejam identificados propriamente para que possam fazer check-in sem problemas

Nome dos passageiros : O nome ajuda a vincular a pessoa física a sua identidade e também permite a companhia chamar a pessoa pelo nome na hora do embarque

Data dos voos: Garante que os passageiros e os funcionários possam se organizar propriamente para que o voo ocorra sem problemas

Local de embarque: Garante que os passageiros saibam exatamente onde tem que estar na hora de embarcar

Horário de embarque: Garante que os passageiros saibam exatamente o horário em que devem estar prontos no local de embarque, também diz aos funcionários quando anunciar que o embarque vai começar 

Destino: Como objetivo de um voo e transportar os passageiros, saber o destino e um pré requisito para que comprem uma passagem, também é fundamental para definir a melhor rota que a aeronave deve seguir

Modelo da aeronave: Permite a equipe se organizar com antecedência para garantir todas as preparações necessárias para a aeronave conseguir realizar o voo inteiro sem problemas

Capacidade da aeronave: Garante que só sejam vendidas passagens dentro do limite de passageiros para evitar problemas de falta de assentos durante o voo

Nome da companhia: Permite os passageiros saberem exatamente com quem tem de falar para ser atendido durante todo o processo de embarque ou para resolver problemas antes e depois do voo

Localização das bagagens: Permite colocá-las no voo certo, garantir que já estão na aeronave antes de decolar, e permite saber se foram retiradas da aeronave para chegar às mãos de seus donos
